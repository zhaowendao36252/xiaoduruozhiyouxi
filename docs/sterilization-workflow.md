# 口腔器械连续处理游戏流程

> 数据优先级：本流程以用户提供的文件名、明确操作要求和场景图片为准；联网资料仅作专业术语与设备外形参考。

## 总体模型

- 项目类型：React + Vite 2D 网页互动游戏。
- 任务结构：7 段参考视频映射为 7 个连续任务，共 58 个原子操作。
- 空间结构：器械预处理区 → 漂洗处理间 → 分拣/包装/灭菌区 → 无菌储存/发放区。
- 主要对象：牙科弯手机 1 把、普通口腔器械 2 件、密闭转运盒 1 个、金属清洗篮 1 个、干燥托盘 1 个、纸塑器械包 3 个、灭菌装载篮 1 个、洁净发放容器 1 个。
- 持久化：状态保存于 `localStorage` 的 `sterilization-workflow-v2`；刷新或返回总览后继续同一批器械。
- 交互节奏：拿取 → 可见移动 → 对准/吸附 → 放置/连接 → 设备操作 → 运行反馈 → 状态更新 → 取出/转移。

## 连续状态

`Dirty → Received → Sorted → Rinsed → UltrasonicWashed → FinalRinsed / AirDried → Lubricated → MachineDried → PostDrySorted → Inspected → Packed → Sealed → LoadedForSterilization → Sterilized → TransferredToStorage → Stored → PreparedForDispatch → Dispatched`

包装约束：

- 手机和普通器械包装后保持在纸塑包装袋内。
- 热封后生成 `sealed=true`，未热封不能装载灭菌。
- 灭菌后生成 `sterilized=true`，包装和密封状态不被清除。
- 储存、取件和发放阶段操作对象始终是密封器械包。

## 视频 1：分拣器械—漂洗—超声酶洗

场景：器械预处理区，随后镜头连续移动到漂洗处理间。

| 起始位置 | 目标位置 | 动作 | 状态变化 | 完成条件 | 主要错误 |
|---|---|---|---|---|---|
| 接收点 | 分拣台 | 整盒搬运密闭转运盒并开锁扣 | Dirty → Received | 转运盒已打开 | 未接收先开盒；送到超声机 |
| 转运盒 | 手机托盘 | 取出牙科手机并单独分类 | handpiece → Sorted | 手机位于专用托盘 | 放入普通器械篮 |
| 转运盒 | 金属清洗篮 | 普通器械装入网篮 | instruments → Sorted | 2 件器械均在篮内 | 未分拣直接超声 |
| 分拣台 | 漂洗槽 | 整篮移动并用水枪漂洗 | Rinsed | 漂洗程序完成 | 器械跳过清洗篮 |
| 漂洗槽 | 超声清洗机 | 移篮、开盖、装篮、关盖、启动 | UltrasonicWashed | 槽盖关闭且程序完成 | 未漂洗装机；未关盖启动 |

与原 Demo 的差异：由一次工具选择/滑动改为转运盒、手机托盘、金属篮、漂洗槽和超声设备之间的连续物品关系。

## 视频 2：牙科手机和普通器械双支线

场景：同一漂洗处理间，以工作位聚焦表现支线切换。

### 牙科手机支线

| 起始位置 | 目标位置 | 动作 | 状态变化 | 完成条件 | 主要错误 |
|---|---|---|---|---|---|
| 手机托盘 | 高压冲洗接口 | 拿取、对准、连接、启动冲洗 | Sorted → Rinsed | 管腔冲洗完成 | 普通器械接入手机接口 |
| 冲洗接口 | 压缩空气枪 | 移动并第一次吹干 | Rinsed → AirDried | 管腔水分排出 | 未吹干进入注油机 |
| 空气枪 | 注油养护机 | 匹配接口、安装、关盖、一键注油 | AirDried → Lubricated | 注油程序完成 | 普通器械放入注油机；未关盖启动 |
| 注油机 | 空气枪 | 取出并再次吹除残油 | Lubricated（保持） | 第二次吹干完成 | 跳过残油排出 |
| 空气枪 | 干燥托盘 | 放入专用位置 | 等待汇合 | 手机位于托盘 | 放回普通清洗篮 |

### 普通器械支线

| 起始位置 | 目标位置 | 动作 | 状态变化 | 完成条件 | 主要错误 |
|---|---|---|---|---|---|
| 超声槽 | 终末漂洗槽 | 开盖、整篮取出、移动 | UltrasonicWashed | 清洗篮到达漂洗槽 | 裸器械瞬移 |
| 终末漂洗槽 | 空气枪 | 终末漂洗后整篮移动并吹干 | FinalRinsed → AirDried | 器械与关节无残水 | 未漂洗进入干燥柜 |
| 空气枪 | 干燥托盘/干燥柜 | 清洗篮入托盘，与手机汇合后装柜、关门、启动 | MachineDried | 两条支线物品都在柜内且程序完成 | 任一支线未完成就启动 |

与原 Demo 的差异：删除“牙科手机当普通小零件”和“滴油瓶”表现，改为专用冲洗接口、两次气枪吹干、12 接口注油养护机和两支线汇合。

## 视频 3：烘干器械转运至分拣台

场景：从干燥设备连续进入分拣、包装和灭菌区。

- 起始：干燥柜内的金属托盘，包含牙科手机与普通器械篮。
- 目标：干燥后分拣台上的手机组合位和普通器械组合位。
- 动作：确认完成 → 开柜 → 整托盘转运 → 逐件取出 → 按包装组合排列 → 必要的带光源放大检查。
- 状态：`MachineDried → PostDrySorted → Inspected`。
- 完成：手机 1 把和普通器械 2 件数量一致，均完成组合和检查。
- 错误：未完成干燥开柜；器械自动出现在桌面；手机与普通器械组合混放。

## 视频 4：打包—包装

场景：包装工作台、纸塑包装袋架、医用热封机和已封装暂存区处于同一画面动线。

- 起始：手机组合位和普通器械组合位。
- 目标：对应尺寸纸塑包装袋 → 热封机导轨 → 已封装暂存区。
- 动作：选尺寸 → 分别装袋 → 整理开口 → 送入导轨 → 启动热封 → 检查连续密封边 → 移到暂存区。
- 状态：`Inspected → Packed → Sealed`，形成 3 个密封器械包。
- 完成：3 件包装全部具有 `packaged=true`、`sealed=true`。
- 错误：尺寸/类别不匹配；裸器械进入灭菌装载；包装袋未封口。

## 视频 5：打包器械进入灭菌设备

场景：已封装暂存区、灭菌装载篮和 B 级压力蒸汽灭菌器。

- 起始：暂存区的 3 个密封器械包。
- 目标：灭菌装载篮 → 压力蒸汽灭菌器腔体。
- 动作：按间距装篮 → 开舱门 → 整篮推入 → 关闭并锁门 → 选择包装器械程序 → 运行并显示反馈/批次记录。
- 状态：`Sealed → LoadedForSterilization → Sterilized`。
- 完成：门已关闭锁定，程序完成，批次内 3 个器械包全部灭菌。
- 错误：裸器械/未封口袋进入；舱门未关闭就启动；跳过装载篮。

## 视频 6：灭菌完成器械转运至储存

场景：灭菌区至无菌储存区的洁净转运通道和传递位置。

- 起始：灭菌器腔体内的金属装载篮。
- 目标：洁净转运车 → 无菌区传递位置 → 储存接收台。
- 动作：确认完成和压力安全 → 开门 → 整篮取出 → 推车转运 → 储存侧交接。
- 状态：`Sterilized → TransferredToStorage`；`sealed` 和 `packaged` 始终为真。
- 完成：3 个密封包完整到达无菌物品接收台。
- 错误：灭菌后拆包；使用污染转运箱；直接瞬移到储存柜。

## 视频 7：无菌柜储存和发放

场景：无菌物品接收台、带分类标签的无菌储存柜、洁净发放容器和发放窗口。

- 起始：储存接收台的 3 个已灭菌密封包。
- 目标：分类柜格 → 洁净发放容器 → 发放窗口。
- 动作：开柜 → 按类别/批次逐件入柜 → 关柜登记 → 接收任务单 → 重新开柜核对 → 取手机包 1 件和器械包 2 件 → 装入洁净容器 → 移至窗口。
- 状态：`TransferredToStorage → Stored → PreparedForDispatch → Dispatched`。
- 完成：正确类别、正确数量、包装完整、均已灭菌的 3 件器械包完成交接。
- 错误：发放未包装/未灭菌器械；类别错误；数量不足；直接从柜内瞬移到窗口。

## 错误反馈实现

状态机只接受当前步骤所需的物品、目标和设备动作。错误时同时返回：

1. 当前错误对象或错误设备。
2. 正确下一步的完整动作提示。

界面另提供“尝试其他设备”和“跳过前置动作”两个错误入口，用于验证状态机确实会拒绝，而不是隐藏错误路径。

## 恢复与兼容

- 每个成功动作立即持久化；返回总览或刷新后继续当前任务、步骤、容器和器械状态。
- 动画结束后才提交移动状态，避免物品先到状态后到画面。
- 设备运行时禁用重复操作，避免快速连点造成重复推进。
- 手机端采用“点击拿取 → 点击目标”；桌面端同时支持拖拽。
- 场景由 HTML/CSS 重建，没有提交带水印、医院名称或设备品牌的用户图片，也没有加载超大原图。

## 与原 Demo 的总体差异

- 12 个互相独立的小关卡改为 7 段视频驱动、58 步连续流程。
- 三个泛化器械图元改为牙科手机、普通器械组、清洗篮、托盘、纸塑包、灭菌装载篮和发放容器的父子关系。
- 不再完成即重新生成器械；数量、位置、包装、密封、灭菌和储存状态跨任务延续。
- 场景从随机卡通背景改为 4 个真实功能区的连续工作位。
- 操作从“选工具后点击/滑动”改为拿取、移动、吸附、装载、开关门、连接接口和运行设备。
- 专业名称替换为“医用超声波清洗机”“压缩空气吹干枪”“牙科手机自动注油养护机”“医用纸塑包装热封机”“B 级压力蒸汽灭菌器”等。
