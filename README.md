# 小小消毒师 · 器械大冒险

面向低龄儿童的 React 响应式互动游戏。游戏以 4 个连续医疗工作区域呈现 7 段、58 个原子操作，完整覆盖口腔器械从污染接收到无菌发放的处理链。

## 运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可。生产构建：

```bash
pnpm build
```

运行状态机测试：

```bash
pnpm test
```

## 关卡流程

1. 污染器械接收、分拣、漂洗与超声酶洗
2. 牙科手机高压冲洗／吹干／注油支线与普通器械终末漂洗支线
3. 干燥器械转运、分拣与检查
4. 医用纸塑包装和热封
5. 装载与压力蒸汽灭菌
6. 灭菌后密封器械包转运至无菌区
7. 无菌柜分类储存与洁净容器发放

同一批器械、托盘、清洗篮、包装袋与转运容器在关卡间保持可追踪状态；错误物品、错误工作位或错误顺序会被拦截并给出正确下一步。游戏进度保存在浏览器本地。
