# 小小消毒师 · 器械大冒险

面向低龄儿童的 React 竖屏互动游戏。游戏使用卡通工作台、工具选择、点击与滑动操作，依次呈现口腔器械清洗消毒的 12 个标准步骤。

## 运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址即可。生产构建：

```bash
pnpm build
```

## 关卡流程

1. 器械预处理
2. 转运分类
3. 超声酶洗
4. 流动水冲洗
5. 自动清洗消毒
6. 干燥
7. 注油
8. 检查
9. 包装
10. 灭菌
11. 储存
12. 发放

游戏进度和星星保存在浏览器本地。点击右上角扬声器可朗读当前任务提示。
